# AML/CFT Risk Assessment System
### ⚠️ Work in Progress — aktivno u razvoju

Full-stack web aplikacija za automatizovanu procjenu rizika od pranja novca i finansiranja terorizma, 
razvijena u skladu sa Zakonom o sprečavanju pranja novca i finansiranja terorizma (Crna Gora, 2023)
i smjernicama FOJ-a.

---

## O projektu

Sistem omogućava obveznicima zakona upravljanje klijentima, automatizovanu analizu rizičnosti kroz 5 grupa faktora rizika,
ponderisanje i kategorizaciju klijenata, 
izračunavanje individualne i ukupne izloženosti obveznika riziku (prijetnja × ranjivost × posljedica),
te automatsko određivanje rokova sljedeće procjene na osnovu nivoa rizika.

---

## Tech Stack

**Backend:** Java, Spring Boot, Spring Security, JWT, JPA/Hibernate, MySQL, Lombok, Maven
